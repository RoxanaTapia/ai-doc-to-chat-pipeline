# How I work with AI

I use AI coding assistants to write and test code faster, so you get working results sooner.

Three things never change:

- **I review every change myself** before it is merged. Nothing reaches the main branch without my approval.
- **I deploy.** No AI tool or automated agent can release to your server.
- **I'm responsible for the result.** If something breaks, fixing it is on me.

You may see "Co-authored-by" lines in the commit history. I keep them on purpose, so you can see where an assistant helped.

The AI model that answers questions inside the product is separate from these coding tools, and you choose which one it uses.

Questions are always welcome.
